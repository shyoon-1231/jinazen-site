## §2 동작

- 🔴 **스크립트 없이도 셋 다 밀어서 보인다** — CSS scroll-snap(`.banner-track` · `scroll-snap-stop:always`).
  실측(iframe `sandbox="allow-same-origin"` = 스크립트 금지): 점 0 · 화살표 0 · `data-auto` 없음 · 트랙 1155/385px · 밀면 ①②③ 이 차례로 0px 에 선다 · ③ 그림도 실린다
- 스크립트(`assets/banner.js`)는 얹기만: 점 셋(단추 · aria-label · aria-controls · aria-current) · 좌우 화살표(PC · 720px 이하 숨김) · 키보드 좌우 · 자동 넘김
- 🔴 **자동 넘김 7초** — 판정: 가장 긴 ② 한 줄(약 90자)을 읽는 데 6초 남짓(어림). 5초면 다 못 읽고, 10초면 ③ 까지 21초라 첫 방문에 셋을 못 본다
- 멈춤 — 실측(가상 시간 · `scrollTo` 를 즉시 이동으로 바꿔 끼워 판정만 쟀다):

| 조작 | 7.5초 뒤 | 15초 뒤 | 상태 |
|---|---|---|---|
| 없음 | 1 | 2 | on |
| 올림(hover) | 0 | 0 | paused |
| 올렸다 떠남(8초) | 0 | 1 | paused → on |
| 초점(focus) | 0 | 0 | paused |
| 터치(pointerdown) | 0 | 0 | stopped (끝까지) |
| 탭 숨김(document.hidden) | 0 | 0 | on (넘기지 않음) |
| 키보드 → | 1 | 1 | stopped |
| 점 셋째 | 2 | 2 | stopped |
| **prefers-reduced-motion** | 0 | 0 | **off** |

- ⚠ 헤드리스 가상 시간에서는 `behavior:"smooth"` 스크롤이 **진행하지 않는다**(0 → 0 실측). 그래서 판정만 재고 부드러운 이동은 **사람 눈 확인**으로 남긴다
- ⚠ 첫 판에서 점 표시(`aria-current`)가 따라오지 않았다 — 스크롤 표시를 `requestAnimationFrame` 에 걸었는데 그리기가 멈춘 창에서 rAF 가 안 돈다. 걸지 않게 고쳤다(재측정 통과)
- 접근성: 바깥 `aria-roledescription="carousel"` · 배너마다 `role="group" aria-roledescription="slide" aria-label="n / 3"` · 트랙 `tabindex=0`
- 🔴 h1 은 ① 에만 하나 · ②③ 은 h2 · 첫 그림(① 사진) preload · ②③ 그림 lazy
- ⚠ WCAG 2.2.2 — 5초 넘게 움직이는 것에는 멈춤 수단이 있어야 한다. 올림·초점 멈춤과 「손대면 끝까지 멈춤」이 있지만 **보이는 「멈춤」 단추는 없다**(지시서 범위 밖 · 미검증)
