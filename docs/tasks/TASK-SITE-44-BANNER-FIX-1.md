## §1 멈춤/재생 단추 (소유자 확정 · WCAG 2.2.2)

- 점 셋 **옆** · `<button type="button" class="banner-pause">` · `aria-pressed`(눌림 = 멈춤) · `aria-label` 「자동 넘김 멈춤」 ↔ 「자동 넘김 재생」
  (en 「Pause/Play auto-advance」 · ja 「自動切り替えを停止/再生」 — 초안) · 그림 글자 ❚❚ / ▶︎ 는 `aria-hidden`
- 🔴 스크립트가 꺼지면 단추도 없다(실측 0개 · 배너는 그대로 밀린다)
- 🔴 동작 줄이기 설정이면 **처음부터 멈춤**(「재생」 · 눌림) — 사람이 「재생」을 누르면 돈다(스스로 고른 것)
- 손으로 넘겨 멈춘 것(터치 · 끌기 · 키보드 · 점 · 화살표)도 이 단추에 멈춤으로 보이고, 누르면 다시 돈다
- 🔴 「재생」을 누르면 잠시 멈춤(올림·초점)도 푼다 — 단추가 배너 **안**에 있어 누르는 순간 초점 멈춤이 걸리기 때문(APG 캐러셀 패턴: 명시적으로 돌리라고 한 것이 이긴다)
- ⚠ 라벨이 상태에 따라 바뀌면서 `aria-pressed` 도 함께 쓰는 것은 소유자 확정 그대로다. APG 는 둘 중 하나(라벨 고정 + pressed, 또는 라벨만 바꿈)를 권한다 —
  화면 읽기 프로그램이 「자동 넘김 재생, 눌림」으로 읽는다. 바꿀지는 소유자 결정
