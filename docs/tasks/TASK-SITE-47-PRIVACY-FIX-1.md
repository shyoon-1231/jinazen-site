
  이것은 섹션이 아니라 **계정 입구**라 언어 전환 옆에 붙였다
- ⚠ en·ja 라벨은 **번역 초안**이다(소유자 확인 전) — 메뉴 여섯과 같은 말투를 따랐다

### 폰 — `display:none` 예외 (WEB-52 확정 ⑦)

```css
옛  @media(max-width:760px){.menu{display:none}}
새  @media(max-width:760px){.menu>a:not(.mypage){display:none}}
```

⚠ `.menu` 를 `display:none` 인 채로 두고 자식 하나만 되살릴 수는 없다 — **부모가 없으면
자식도 없다.** 그래서 부모는 그대로 두고 **나머지 여섯 칸을 숨긴다.** 보이는 칸이 하나뿐이라
`gap` 은 쓰이지 않는다. 자리는 `.nav .wrap` 이 `space-between` 이라 **로고와 언어 전환 사이**다.
